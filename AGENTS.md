# PROJECT
htmlpdf — browser-only HTML+CSS → vector PDF, zero runtime deps
 browser does layout (DOM + getComputedStyle + Range rects); library paints boxes/text into PDF objects
 ES modules, 'type': 'module', MIT

# DIRECTORY
./
 .github/workflows/ — CI release automation
 src/ — library source (index.js, paint.js, writer.js, fonts.js)
 site/ — static pages copied into dist/ (the GitHub Pages root) (index.html: interactive playground + examples + generated code); imports ./htmlpdf.esm.min.js; build.js copies site/ → dist/ (dist/ is gitignored)
 site/llms.txt — LLM-oriented API summary + live URLs, served at the Pages root; update when API, options or supported CSS change
 dist/ — build output (gitignored, generated by pnpm run build)

# ENTRY-POINTS
src/index.js — public API (htmlToPdf, helpers, registerFont, registerFontUrl); build.js bundles it
build.js — esbuild bundler → dist/
.github/workflows/release.yml — auto tag + GitHub release on push to main
.github/workflows/pages.yml — build + deploy dist/ to GitHub Pages on push to main

# MODULES
src/index.js — htmlToPdf: offscreen host div, font load/auto-discovery, render, PdfDoc.build; downloadPdf/openPdf/printPdf/pdfBlobUrl
src/paint.js — DOM walker; paints backgrounds, gradients (linear/radial/conic), borders, shadows (outer/inset), clip-path, pseudo-elements/::after materialised as spans, list markers, images, text, pagination → Page ops; non-mutating box measurement (translate compensated, rotation/scale neutralised temporarily)
src/writer.js — PdfDoc/Page: PDF objects, content stream ops, shading, images, deflate via CompressionStream; Type1 WinAnsi text
src/fonts.js — registry (TrueType embedder CIDFontType2 Identity-H + ToUnicode), glyph subsetter (keeps used glyphs + composite deps; only head/hhea/maxp/hmtx/loca/glyf emitted), Standard 14 fallback (Helvetica/Times/Courier), @font-face discovery (ttf/data URLs)

# ARCHITECTURE
src/index.js → src/paint.js (render, MM) → src/fonts.js (pickFont)
src/index.js → src/writer.js (PdfDoc)
src/index.js → src/fonts.js (registerFont, hasFonts)
units: CSS px, y down; writer base matrix flips to PDF space (K=0.75)
pagination: paginate() pushes margin-top for break-before/break-inside (forces the whole first line past the boundary via line-height); page i clips window i*contentH
text: per-char Range rects → words; fallback to per-char positioning when predicted width differs >0.35px
images/svg/canvas rasterised via canvas → RGB + SMask
gradients: opaque → PDF shading; translucent → rasterised

# SCHEMA
htmlToPdf(input: string|Node, opts) → Promise<Uint8Array>
opts: width=210 height=297 margin=0 background='#fff' hairline=0 css='' fonts=[{family,weight,style,url}] noAutoFonts=false (auto-discover @font-face)

# ENV
runtime: modern browser (DOM, canvas, CompressionStream optional)
build: node >=18, pnpm (pnpm-lock.yaml committed, CI uses --frozen-lockfile), devDependency esbuild
CI: GITHUB_TOKEN (contents: write)

# BUILD
pnpm run build → dist/htmlpdf.esm.min.js, dist/htmlpdf.min.js (IIFE global htmlpdf), unminified + sourcemaps
version source: package.json version; release tag = v<version>

# TESTING
pnpm test → node --test over test/*.test.js (no browser: PdfDoc xref/structure, shading+SMask output, font validation); CI and release run it before build

# INVARIANTS
no runtime dependencies
no build step required for source consumption
pickFont never returns null — std-14 fallback always yields a font
deflate() reads cs.readable concurrently with the write — awaiting write first deadlocks on backpressure; any stream error returns null (uncompressed fallback)
