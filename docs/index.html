What does what? (cheat sheet)
Call Does
htmlToPdf(input, opts) Main function. input is an HTML string or a DOM node (cloned). Returns Promise<Uint8Array> with the PDF bytes.
downloadPdf(pdf, name) Saves the PDF as a file.
openPdf(pdf) Opens it in a new tab.
printPdf(pdf) Opens the print dialog through a hidden iframe.
pdfBlobUrl(pdf) Gives a blob: URL, for example for an iframe preview (what this page does).
opts.fonts The same .ttf files your CSS uses, one entry per weight and style. Required: the PDF embeds these exact fonts.
break-before: page CSS that starts a new PDF page. break-inside: avoid keeps a block on one page.
Not supported ::before/::after, list markers, inset shadows, filters, blend modes, clip-path, conic gradients.
